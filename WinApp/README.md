# Native Windows App (WPF)

This folder contains a minimal WPF application written in C# as a starting point for converting the Electron-based Attendance Tracker into a native Windows application.

The project uses .NET 8 and WPF. All actual features from the React application would need to be reimplemented in this code base. For now, the app just displays a welcome window.

## Building

Use Visual Studio 2022 or `dotnet build` on Windows to compile the project. Running the resulting executable will show the placeholder main window.
